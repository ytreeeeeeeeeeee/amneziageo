AmneziaGeo - кроссплатформенный VPN-клиент для Windows, Linux и Android на базе AmneziaWG, доработанного WireGuard. Раздельное туннелирование (split tunneling) направляет выбранный трафик через ваши серверы. На Windows можно подключить несколько VPN одновременно и выбрать сервер для каждого правила маршрутизации.

**[Скачать](https://github.com/ytreeeeeeeeeeee/amneziageo/releases) · [Документация](https://bor-project.github.io/amneziageo/index.ru.html) · [Сервер](https://github.com/ytreeeeeeeeeeee/amneziageo_server/blob/master/README.ru.md)**

## Возможности

- Несколько VPN одновременно на Windows: основной и резервные серверы, выбор сервера для каждого правила.
- Полный и раздельный туннель по доменам, категориям сайтов, странам, диапазонам IP и приложениям с одновременным выбором нескольких списков маршрутизации.
- Маршрутизация доменов по DNS и доступ к сетям за серверами. Маршрутизация приложений экспериментальная; подробности - в разделе маршрутизации для [Windows](https://bor-project.github.io/amneziageo/windows/menu/routing.ru.html#маршрутизация-приложений), [Linux](https://bor-project.github.io/amneziageo/linux/menu/routing.ru.html#маршрутизация-приложений) и [Android](https://bor-project.github.io/amneziageo/android/menu/routing.ru.html#маршрутизация-приложений).
- WebSocket поверх TCP для сетей, блокирующих UDP.
- SOCKS5- и HTTP-прокси для других устройств в локальной сети.
- Диагностика маршрутов, проверка скорости и единый интерфейс командной строки.

Windows 7, 10 и 11 (x64 и ARM64), Linux (пакеты deb для amd64 и arm64) и Android.

Пакеты для установки доступны в [релизах форка](https://github.com/ytreeeeeeeeeeee/amneziageo/releases).
Настройка, команды CLI и сборка из исходников описаны на **[сайте документации](https://bor-project.github.io/amneziageo/index.ru.html)**.

## Списки маршрутизации

Откройте раздел **Маршрутизация** и включайте или выключайте списки переключателями на их карточках. Выбор общий для
VPN-конфигураций, в которых включена **Маршрутизация**. Переключатель на главном экране выключает весь набор и при
повторном включении восстанавливает последний доступный выбор. Если списки не выбраны, действуют маршруты
VPN-конфигурации (`AllowedIPs`).

- Если хотя бы в одном выбранном списке включено **Всё через VPN**, VPN становится маршрутом по умолчанию. Явные прямые
  и блокирующие правила продолжают действовать. Если все списки выборочные, трафик для VPN выбирается по правилам.
  Запрос **Весь UDP через туннель** от любого списка включает общий флаг. Его действие зависит от режима туннеля.
- Правило распознанного домена важнее правила приложения. Если домены на общем IP имеют разные правила и домен
  соединения неизвестен, применяется правило приложения. Явная блокировка по IP сохраняет приоритет.
- При первом получении пресетов с сервера клиент включает все пресеты с отметкой **Включён по умолчанию**, если
  сохранённого выбора ещё нет. Дальнейшая синхронизация учитывает ручные изменения. В режиме **Только списки сервера**
  должен быть выбран хотя бы один разрешённый пресет.

**Windows** применяет новый набор при переподключении. **Android** пытается переподключить активный VPN автоматически.
**Linux** может применить совместимые изменения доменных и IP-правил на ходу. Изменения режима VPN, правил приложений
или действующей политики UDP требуют переподключения. Сверяйте **Выбрано списков** и **Применено списков** в приложении
или выполните `amneziageo routing selection` на Windows или Linux.

### Пример с двумя списками приложений

Создайте список **Яндекс Диск напрямую**, добавьте Яндекс Диск в **Напрямую** и включите **Всё через VPN**. Создайте
выборочный список **Discord через VPN** и добавьте Discord в **Через VPN**. Оставьте **Весь UDP через туннель**
выключенным в обоих списках. Используйте записи приложений для своей платформы.

Включите оба списка и дождитесь применения. Яндекс Диск пойдёт напрямую, а Discord и остальной трафик без отдельных
правил пойдут через VPN. Выключите **Яндекс Диск напрямую** и примените изменение. Число применённых списков уменьшится
с двух до одного, режим сменится на **Только выбранное**, Discord останется в VPN, а трафик без совпадений пойдёт
напрямую.

## Сервер

**[AmneziaGeo Server](https://github.com/ytreeeeeeeeeeee/amneziageo_server/blob/master/README.ru.md)** - панель управления своим сервером AmneziaWG на Linux: клиенты с конфигурациями, QR-кодами и подписками, шаблоны, маршрутизация по гео-базам и доменам через другие серверы, резолвер для клиентов. Гео-источники, списки маршрутизации и подписку такого сервера клиент читает сам; любой другой сервер AmneziaWG тоже подходит. Установка и настройка - на **[сайте документации сервера](https://bor-project.github.io/amneziageo_server/index.ru.html)**.
